Templates d'exercices — grammaire
=================================
Saisis ici tes phrases / items, puis recopie-les dans les fichiers
lib/curriculum/content/francais/grammaire-g*.ts (champ exercises[]).

Blanc dans une phrase : exactement  ___  (trois underscores).
Aperçu interactif (hors menu élève) : /francais/grammaire/a1-gr-templates

Légende
-------
EXISTANT  = type déjà utilisé dans la grammaire, ne pas recréer.
NOUVEAU   = type ou champ ajouté pour ce catalogue.

----- 5.2 Remise en ordre de mots                          EXISTANT  type: word_order -----
mange / une / Je / pomme  →  « Je mange une pomme. »
Les mots doivent correspondre EXACTEMENT à la phrase (casse comprise).
Le point final est ajouté tout seul s'il est à la fin de sentence.

{
  type: "word_order",
  title: "Exercice 20",
  instruction: "Remets les mots dans l'ordre.",
  items: [
    { sentence: "Je mange une pomme.", words: ["Je", "mange", "une", "pomme"] },
  ],
}

À saisir :
# phrase cible | mots séparés par /
Je mange une pomme. | Je / mange / une / pomme

================================================================================
CHAMPS MÉDIA (optionnels, tous templates)
================================================================================
audioText        texte lu (mp3 mot si un seul mot, sinon TTS)
imageWord        mot → /assets/words/lecture/<mot>.webp
image            chemin d'image explicite
svg              SVG inline
choiceImageWords tableau parallèle aux choices (QCM)
correctIdxs      index des bonnes réponses (QCM multiple)
correction       texte à écrire si l'affirmation est fausse (V/F)
requiredWords    mots que la phrase produite doit contenir (write)
parts            répliques d'un dialogue à ordonner (order)
imageWords       images à ordonner (order)
choices          liste locale d'un trou (fill_select, QCM intégré)
